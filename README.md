# Bob's Lab

基于 Firestone 英雄统计, 用蒙特卡洛抽样比较炉石传说酒馆战棋的英雄选择策略.

## 使用

需要 Python 3.14+ 和 uv. 在项目根目录执行:

```bash
uv sync
uv run bobs-lab
```

按提示选择时间窗口、模拟次数、随机种子和策略. 默认最新补丁、1M 次、种子 42、平均排名优先; Esc 退出.

支持平均排名、选取率、胜率 (单打前四/双打前二) 和第一率策略, 比较 2/4/5/6/7/8 个候选英雄在单双打及各 MMR 分组下的平均排名.

## 输出

| 路径 | 内容 |
| --- | --- |
| `data/` | Firestone 原始英雄统计 JSON |
| `result/summary-<uuid前6位>.xlsx` | 平均排名汇总表及 `metadata` 运行参数与数据更新时间 |

模拟复用各 MMR 分组共有的英雄池, 抽取记录仅保存在内存中. 结果反映所选英雄的统计平均排名, 不模拟实际对局.
